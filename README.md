# 🎮 Simon-Style Memory Game

## Overview
This is an interactive **Simon-style memory game** built with **HTML, CSS, and JavaScript**. Players must memorize and replicate an increasing sequence of colored buttons. The game tests memory, reaction, and focus.

---

## 🎨 Features
- **🌈 Animated Gradient Background:** Smooth 400% x 400% gradient animation for visual appeal.  
- **💡 Flashing Color Buttons:** Buttons flash in a sequence to memorize.  
- **🎵 Sound Effects:** Click sounds, start notifications, and game over sounds for immersive experience.  
- **🏆 Score Card:** Displays final score with motivational quotes on game over.  
- **🖱️ Responsive Gameplay:** Handles clicks, validates sequences, and resets for multiple rounds.  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3 (animations & transitions)  
- JavaScript (DOM manipulation, event handling, audio integration)  

---

## ▶️ How to Play
1. Press any key to start the game.  
2. Observe the sequence of flashing colored buttons.  
3. Click the buttons in the correct order to match the sequence.  
4. Repeat until a wrong button is clicked.  
5. Your score and a motivational quote appear when the game ends.
